#  Rock Paper Scissors

A simple **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**.

The player selects Rock, Paper, or Scissors, and the computer randomly generates its choice. 
The game then determines the winner and keeps track of the scores.

##  Features

- 🪨 Rock, 📄 Paper, and ✂️ Scissors buttons
-  Random computer choice
-  Player choice display
-  Automatic winner detection
-  Player and computer score tracking
-  Selected choice is highlighted
-  Choices reset after every round
-  Simple and interactive UI

##  How to Play

1. Select **Rock**, **Paper**, or **Scissors** emoji/buttons.
2. Your selected button will be highlighted.
3. Click the **PLAY** button.
4. The computer generates a random choice.
5. The choices are displayed.
6. The winner is determined automatically.
7. The score is updated.

## 🛠️ Technologies Used

- **HTML** — Structure of the game
- **CSS** — Styling and layout
- **JavaScript** — Game logic and interaction
